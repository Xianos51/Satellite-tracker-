# MISTRAL // Orbital Tracking Console

Real-time 3D tracker of satellites and space debris orbiting Earth, fed by **live TLE data
from [CelesTrak](https://celestrak.org)** and propagated in the browser with **SGP4**
([satellite.js](https://github.com/shashwatak/satellite-js)). Styled as a Mistral
mission-control console. No backend — it runs natively in any modern browser.

## Run it

**Double-click `index.html`** — it is a single self-contained file (all CSS/JS/textures
inlined, ~1.5 MB), so it works from `file://` with no server and no sibling files.
The TLE feed is CORS-enabled, so live data loads straight from the browser.

If you edit the sources under `src/`, regenerate the single file with:

```bash
python3 build.py
```

Or serve the folder for development: `python3 -m http.server 8137` → http://127.0.0.1:8137/

Requires internet for the live TLE feed. If the feed is unreachable, an embedded
sample TLE snapshot is loaded and the badge switches to `OFFLINE — SAMPLE DATA`.
If **WebGL is unavailable** in the browser (blocked GPU, remote desktop, VM), the
console automatically switches to a **2D orthographic map mode** (same data, same
picking/telemetry) and shows a red `SYS //` banner explaining why. Any script error
is likewise shown in the banner instead of failing silently.

## What it does

- Fetches live TLE groups from CelesTrak (`gp.php?GROUP=…&FORMAT=tle`): space stations,
  recent launches, Starlink, OneWeb, Kuiper, Qianfan, bright/visual, GPS, weather, GEO,
  CubeSats, science, and the Fengyun-1C / Cosmos-2251 / Iridium-33 debris clouds, plus
  the full active catalog (heavy, ~20k objects).
- CelesTrak rate-limits each group to one download per 2 h per IP, so responses are
  cached in `localStorage` (115 min TTL) and reused; the REFRESH button re-fetches and
  gracefully falls back to cache with a notice.
- Every object is propagated in real time with SGP4 (time-sliced round-robin so 20k+
  objects stay smooth at 60 fps) and rendered as a point in an inertial (ECI) frame;
  the Earth rotates underneath by GMST.
- Textured Earth (day + night-lights emissive), graticule, atmosphere rim glow,
  starfield, sun sprite.
- Click any object (or search by name / NORAD ID) to lock a target: live altitude,
  velocity, lat/lon, look angles (az/el/range/visibility) from **CSG Kourou** ground
  station, full orbital elements, predicted orbit line, and a camera focus mode.
- Time controls: pause, 1× / 10× / 60× / 600× / 3600× sim rate (default 60×).
- Load your own `.tle` file via the left panel for offline catalogs.

## Controls

| Input | Action |
|---|---|
| mouse drag / wheel | orbit / zoom camera |
| click object | select target (telemetry + orbit line) |
| hover | name tooltip |
| `F` | focus camera on target |
| `ESC` | reset view |
| `SPACE` | pause / resume sim |
| `+` / `-` | sim speed |
| `R` | refresh TLE data |
| `/` | focus search box |

## Layout

```
index.html          BUILT single-file app (double-click this) — generated by build.py
build.py            inlines src/ into the root index.html
src/index.html      console shell template
src/css/console.css mission-control theme (Mistral orange gradient on dark)
src/js/tle.js       CelesTrak fetch + localStorage cache + TLE parser
src/js/scene.js     Three.js scene: Earth, graticule, atmosphere, point clouds
src/js/scene2d.js   2D canvas fallback renderer (used when WebGL is unavailable)
src/js/app.js       sim loop, SGP4 propagation, picking, telemetry, UI
src/js/textures.js  Earth day/night textures embedded as data URIs (file://-safe)
src/js/sample-data.js  embedded fallback TLE snapshot
src/lib/            vendored three.js r147, OrbitControls, satellite.js v4
assets/             source Earth textures (4096px)
screenshots/        verification captures (see shoot.py / probe.py)
shoot.py, probe.py  headless-Chromium dev harness used to verify the app
apps.json           Mistral App manifest (static "web" module, port 3001)
apps/web/server.js  dependency-free static server for the module
deploy/docker/Dockerfile.web  image that serves the built index.html
```

## Deploy as a Mistral App

The repo is a Mistral App project (`apps.json` + `deploy/docker/Dockerfile.web`,
capabilities `core` + `apps` in `.mistral/capabilities.json`). The platform builds the
pushed commit of this repository (the `mistralai` GitHub app must have access to it):

```bash
mistral login            # one-time browser sign-in
mistral deploy           # builds the pushed commit and serves it in production
```

Then verify with the Studio tools (`list_apps`, `get_app`, `list_app_deploy_runs`) and
optionally publish the environment to the apps catalog with `publish_app`.

Data: TLE © CelesTrak / US Space Force. Earth textures: three-globe example imagery
(NASA Blue Marble / night lights).
